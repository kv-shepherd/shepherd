# Deprecated: Bootstrap Role SOP

This document name is kept only as a compatibility pointer for older design
notes and links.

The public RBAC baseline no longer defines a dedicated `role-bootstrap`.
Initial access now uses the seeded default admin account plus the canonical
`role-platform-admin` built-in role.

Use the current procedure instead:

* [Platform Administrator Bootstrap and Review SOP](./platform-admin-sop.md)
